# Results

Generated by `tools/summarize.py` from [`ledger.csv`](ledger.csv). Do not edit by hand; run the script.

How to read these tables:

- A **session** is one fresh Claude Code (or chat) conversation. Counts are sessions, not tasks.
- **Activated** means the Capability Scout skill ran in that session. **Scout before work** means it ran before any other work tool. Definitions: [`docs/ANALYSIS_PLAN.md`](../docs/ANALYSIS_PLAN.md).
- The 95% interval is a Wilson score interval. Repeated runs of the same task are not independent, so the interval is narrower than it should be. A rate here is a measured rate for that task set, not a promise for all tasks.
- Batches whose names start with `legacy-` were imported from earlier evidence. Their `notes` column says how good that evidence is.
